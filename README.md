#  author-today-neurodetector

Автоматическая проверка книг с [author.today](https://author.today) на нейросетевой текст через API [Yandex NeuroDetector](https://yandex.ru/lab/neurodetector).

---

>  **Важно:** Парсятся только **бесплатные фрагменты** произведений. Если книга содержит платные главы, анализ выполняется по части текста. Результат на полном произведении может отличаться от показанного.

##  Что делает

| Шаг | Описание |
|---|---|
| **Парсинг** | Загружает страницу книги, получает оглавление, парсит текст глав через Selenium |
| **Остановка** | Автоматически останавливается на первой платной главе |
| **Проверка** | Отправляет весь распарсенный текст в Yandex NeuroDetector API |
| **Результат** | Показывает % AI / Human по сегментам + вердикт |

### Принцип работы

1. **Оглавление** — скрипт загружает страницу произведения (`/work/{id}`) и извлекает список глав из вкладки «Оглавление» (`ul.table-of-content`). Никакого JavaScript — чистый HTML.

2. **Текст глав** — каждая глава открывается в headless Chrome (Selenium), потому что author.today рендерит текст на клиенте через Knockout.js. Текст извлекается из `#text-container > p`.

3. **Платные главы** — при обнаружении индикаторов платного доступа парсинг останавливается. Анализируется только бесплатный фрагмент.

4. **NeuroDetector** — текст отправляется POST-запросом на скрытый API `POST /lab/neurodetector/api/analyze/text`. Yandex разбивает текст на сегменты и классифицирует каждый: `AI`, `LIKELY_AI`, `LIKELY_HUMAN`, `HUMAN`.

##  Предупреждение: Selenium и антивирусы

Проект использует **Selenium + headless Chrome** для получения текста глав, так как author.today рендерит контент на клиенте через JavaScript (Knockout.js).

**Некоторые антивирусы могут ругаться на Selenium:**

- Selenium управляет браузером программно, что похоже на поведение ботов
- Headless-режим Chrome может вызывать подозрения у защитных систем
- Возможны ложные срабатывания при запуске `chromedriver.exe`

**Что делать:**

- Добавьте папку проекта в исключения антивируса
- При необходимости — добавьте `chromedriver.exe` из кэша `webdriver_manager` в исключения
- Не отключайте антивирус полностью — достаточно добавить исключение для конкретной папки

##  Принцип работы (подробно)

### Парсинг author.today

1. **Страница книги** (`GET /work/{id}`) — извлекается заголовок, автор и оглавление. Данные находятся в чистом HTML, без JavaScript.

2. **Страница главы** (`GET /reader/{book_id}/{chapter_id}`) — открывается в Selenium, ждём появления `#text-container`, извлекаем `<p>` элементы.

3. **Детекция платных глав** — проверяются ключевые контейнеры на индикаторы: «платный доступ», «для продолжения чтения», «закрытый контент» и кнопки покупки.

### Yandex NeuroDetector API

- **Endpoint:** `POST https://yandex.ru/lab/neurodetector/api/analyze/text`
- **Формат запроса:** `{"text": "..."}`
- **Формат ответа:**
  ```json
  {
    "ok": true,
    "results": {
      "stats": {
        "segments_count": 100,
        "AI_count": 10,
        "LIKELY_AI_count": 15,
        "LIKELY_HUMAN_count": 30,
        "HUMAN_count": 45
      },
      "segments": [ ... ]
    }
  }
  ```

##  Дисклеймер

> Данный инструмент предназначен **только для ознакомительных целей**. Парсинг данных с author.today выполняется для облегчения нейродетекции — автоматической проверки текста на наличие следов генерации ИИ.
>
> Результаты проверки носят **оценочный характер** и не являются юридическим заключением. Анализ выполняется только по бесплатному фрагменту произведения, который может не отражать стиль автора на всём объёме книги.
>
> Разработчик не несёт ответственности за использование данного инструмента.

##  GUI

Интерфейс включает:

- **Поле ввода URL** — многострочное, поддержка Ctrl+C/V
- **Настройки** — макс. глав, задержка между запросами (сек)
- **Прогресс-бар** — с процентами выполнения
- **Результаты** — с кнопкой копирования в буфер обмена
- **Лог** — детальный прогресс по главам в реальном времени
