# 🔍 author-today-neurodetector

Автоматическая проверка книг с [author.today](https://author.today) на нейросетевой текст через API [Yandex NeuroDetector](https://yandex.ru/lab/neurodetector).

Программа делает то, что вручную утомительно: открывает книгу, собирает текст доступных глав, отправляет его в детектор Яндекса и показывает вердикт — с процентом ИИ-текста и разбором по главам. Можно проверять по одной книге и пачками в сотни ссылок.

> ⚠️ **Важно.** По умолчанию анализируется только **бесплатный фрагмент** произведения. Если у книги есть главы, закрытые платным доступом, программа честно пишет их число, но вердикт относится к той части, что была доступна. Результат на полном тексте может отличаться.

📦 **Нужен результат по одной книге прямо в браузере?** Есть облегчённая версия — [расширение для Chrome](https://github.com/LeDXIII/author-today-neurodetector-extension). Оно работает в твоём аккаунте и не требует Python. Десктопная программа сильнее в массовых проверках: пачки ссылок, повторы сбоев, история, экспорт, доступ к купленным главам через аккаунт.

## ✨ Возможности

- **Пакетная проверка** — вставил список ссылок (по одной в строке), получил таблицу результатов.
- **Устойчивость к сбоям** — каждая глава грузится с повторами; если Chrome упал, он поднимается заново; если Яндекс не ответил с первого раза, запрос повторяется. Одна ошибка не обрывает проверку книги.
- **Длинные тексты** — отправляются во «фрагментах», потому что детектор Яндекса обрывает обработку примерно на 30-й секунде. Для книги в 250 000 знаков это разница между «вердикт есть» и «книга упала без результата».
- **Отмена в любой момент** — кнопка «Стоп» прерывает на ближайшей главе, а уже собранное всё равно уходит в детектор.
- **Повтор только упавших** — «Перепроверить упавшие» без пере-парсинга сайта: текст книги лежит в локальном кэше.
- **Доступ к аккаунту** — если вписать логин в `.env`, программа проверяет и купленные с этого аккаунта главы.
- **История проверок** — все запуски складываются в локальную базу, с поиском и фильтрами.
- **Экспорт** — текстовый отчёт (удобно вставить в чат), CSV (Excel) и JSON.
- **Подробный разбор** — по каждой главе видно, сколько символов собрано, откуда, с скольких попыток; по каждому фрагменту — сколько сегментов стало ИИ/человеком.
- **Логи** — каждый записывается в файл, чтобы сбой можно было показать и разобрать.

## 🚀 Установка

Не страшно, если ты ни разу не запускал Python-программы — ниже по шагам, что и куда нажимать.

### Шаг 1. Что понадобится

| Что | Зачем |
|---|---|
| Windows 10/11 | программа проверяется на Windows |
| **Google Chrome** | текст глав отдаётся только настоящему браузеру |
| **Python 3.10 или новее** | среда выполнения (ставится один раз, ~5 минут) |
| ~200 МБ свободного места | зависимости и браузерный драйвер |

### Шаг 2. Скачай программу

Скачай архив репозитория (зелёная кнопка **Code → Download ZIP**) или клонируй:

```cmd
git clone https://github.com/LeDXIII/author-today-neurodetector.git
```

Распакуй в любое место, **где в пути нет кириллицы и пробелов**, например `D:\neurodetector`. Распакованный файл `install.bat` должен лежать рядом с папкой `src`.

### Шаг 3. Установи Python

Сначала проверь, вдруг он уже есть. Нажми `Win + R`, введи `cmd` и нажми Enter, затем:

```cmd
python --version
```

Если показалось `Python 3.10.x` (или выше) — переходи к шагу 4. Если «не является внутренней или внешней командой» — ставим:

1. Открой https://www.python.org/downloads/
2. Нажми **Download Python 3.x.x** (любую версию 3.10 и новее; автор проверял на 3.10).
3. При установке **обязательно поставь галочку** `Add python.exe to PATH` внизу первого окна установщика — без этого программа не найдёт Python.
4. Дождись `Setup successful`, закрой и открой окно `cmd` заново (оно запоминает PATH только при запуске) и снова выполни `python --version`.

### Шаг 4. Установи зависимости

Дважды кликни **`install.bat`**. Он сам:

- создаст изолированное окружение в папке `venv` (ничего в системе не трогает);
- установит PyQt6, Selenium и остальные библиотеки;
- скачает драйвер Chrome;
- создаст файл `.env` из шаблона (он не обязателен — см. раздел про аккаунт).

Норма, что шаг с зависимостями занимает пару минут и много пишет в окно. В конце должно быть `Готово! Запустите run.bat для старта GUI`.

### Шаг 5. Запуск

Дважды кликни **`run.bat`**. Откроется окно «Author Today — NeuroDetector».

Первый запуск может занять больше обычного: поднимается браузер. Дальше книги идут быстрее.

## 🖥 Как пользоваться

### 1. Вставь ссылки

В верхнее поле — по одной ссылке в строке. Принимаются все варианты:

```
https://author.today/work/618826
/work/646328
624916
https://author.today/reader/618826/5908671
```

Программа убирает повторы (одна книга = одна строка результата) и показывает снизу «книг: N» — а нераспознанные строки не теряются: перед стартом она спросит, продолжать ли с остальными. Кнопка **«Список из файла»** загружает ссылки из `.txt`/`.csv`.

### 2. Настрой при желании

В одну строку вынесено главное:

| Поле | Смысл |
|---|---|
| **Макс. глав** | Сколько глав взять с книги. Больше глав → точнее вердикт (детектор любит объём) и дольше проверка |
| **Задержка, с** | Пауза между главами. Уменьшай, только если уверен, что сайт не обидится |
| **вход из .env** | Проверять и доступные аккаунту главы (см. ниже) |
| **пропускать свежие проверки** | Не пере-парсить книгу, которую уже успешно проверили за последние сутки — удобно при длинных списках |
| **Ещё…** | Сколько ждать отрисовку страницы, таймаут загрузки, число попыток на главу и на запрос, размер фрагмента, режим без окна браузера, не грузить картинки, кэш текста |

Настройки запоминаются до следующего запуска.

### 3. Смотри таблицу

Каждая строка — книга: статус, главы «собрано/доступно», пропуски, число закрытых глав, объём в знаках, **% ИИ**, вердикт (окрашен по порогу), время. Фильтры сверху: все / только с ошибками / подозрение на ИИ / с платными главами; поиск по названию, автору или ID.

Двойной клик по строке — подробности: по главам (статус, символов, источник, число попыток) и по фрагментам детектора.

### 4. Остановка и повтор

**«Стоп»** прерывает на ближайшей главе — обычно в пределах нескольких секунд. Всё, что успело собраться, уходит в детектор, и вердикт по собранному ты получишь (в столбце статуса это помечено).

**«Перепроверить упавшие»** запускает только книги без вердикта. Если их текст сохранился в кэше, сайт не трогается вообще — летит только запрос в Яндекс, это секунды.

### 5. Сохрани результат

**«Экспорт»** — TXT (читаемый отчёт для пересылки), CSV (Excel, разделитель `;`, кириллица корректна) или JSON. **«Копировать отчёт»** кладёт то же самое в буфер обмена. Вкладка **«История»** — все проверки прошлых запусков; там же кнопка «Очистить кэш текста», если папка с БД разрослась (записи останутся, удалятся только кэшированные тексты).

## 🔐 Проверка купленных книг (аккаунт)

По умолчанию программа анонимна и видит только бесплатные главы. Если нужна проверка купленного:

1. Открой файл **`.env`** в папке программы (создаётся установщиком; если пропал — скопируй `.env.example` в `.env`).
2. Впиши логин и пароль:
   ```
   AT_LOGIN=твоя-почта
   AT_PASSWORD=твой-пароль
   ```
3. Сохрани и поставь галочку **«вход из .env»**.

Дальше программа входит на сайт и переносит сессию в браузер. Для аккаунта, у которого книга куплена или открыта подпиской, главы в оглавлении перестают быть закрытыми и парсятся наравне с бесплатными — то есть вердикт будет по большему объёму текста.

В левом нижнем углу видно, как прошла попытка: **«сессия: авторизован»** или **«анонимно»** (наведи мышку — будет причина). Неудачный вход не ломает проверку: программа просто продолжает работать анонимно.

- `.env` не попадает в репозиторий (он в `.gitignore`), пароль никуда не логируется.
- **Аккаунты с 2FA не поддерживаются** — код из письма вводить негде, программа уйдёт в анонимный режим.

## ⚙️ Как это работает

### 1. Оглавление

Программа читает страницу `/work/{id}` по HTTP и берёт список глав из `ul.table-of-content`. Здесь важная деталь: **закрытая платным доступом глава отдаётся без ссылки** — в оглавлении это строка с иконкой замка и подсказкой «Платный доступ». Такие главы считаются отдельно и показаны в колонке «Замки», чтобы «8 из 8» никогда не выглядело как полная книга, если на самом деле глав 23.

### 2. Текст глав

Сам текст author.today рисует скриптом (Knockout.js): в исходном HTML контейнер главы пуст. Поэтому каждая глава открывается в настоящем браузере (headless Chrome), и программа ждёт, пока объём текста **перестанет расти**, а не фиксированное число секунд. Получившееся вычитывается из абзацев контейнера; если абзацев нет — из контейнера целиком; и только в крайнем случае — из текста страницы (такие главы помечаются источником `body`, потому что в них мог попасть служебный текст сайта).

### 3. Платные главы

Глава признаётся платной, если текста нет **и** на отрисованной странице виден блок оплаты. Это два обязательных условия: иначе любая заминка загрузки выглядела бы как «книга кончилась». Найденная платная глава останавливает обход, а собранный до неё текст отправляется на проверку.

Различия принципиальные:
- **ошибка загрузки** → повтор (до 3 попыток, с нарастающей паузой; при падении браузера он поднимается заново) → если не помогло, глава помечается пропущенной, **книга продолжается**;
- **платная глава** → остановка обхода, переход к детекции.

### 4. Отправка в NeuroDetector

Запрос — `POST https://yandex.ru/lab/neurodetector/api/analyze/text`, тело `{"text": "..."}`, **без авторизации и без API-ключа**. Яндекс режет текст на сегменты и помечает каждый: `AI`, `LIKELY_AI`, `LIKELY_HUMAN`, `HUMAN`.

Один большой запрос — узкое место: измерено, что сервер обрывает обработку примерно на 30-й секунде (400 000 знаков отвечает за ~21 с, 700 000 — обрыв на 30 с). Поэтому текст режется на фрагменты примерно по 90 000 знаков **по границам глав**, а статистика фрагментов суммируется. Классификация идёт по сегментам, поэтому сумма по фрагментам даёт тот же вердикт, что и один большой запрос, — только без обрывов.

### 5. Повторы и частичный результат

Ошибки сети, обрывы соединения, 5xx и 429 (с учётом `Retry-After`) повторяются до 4 раз с экспоненциальной паузой. Если API сам заявит, что фрагмент слишком длинный, он делится пополам и проверяется двумя запросами. Если часть фрагментов всё-таки не проверилась, строка получает статус **«частично»** и в ошибке пишется, что именно упало — никакого «результат получен» после отказа.

### 6. Вердикт

Процент ИИ считается от классифицированных сегментов: `(AI + LIKELY_AI)` против `(HUMAN + LIKELY_HUMAN)` — той же формулой, что и браузерное расширение, так что две программы на одном тексте не расходятся.

## 📋 Статусы строк

| Порог % ИИ | Вердикт |
|---|---|
| ≥ 50 | 🔴 Большая часть текста вероятно сгенерирована ИИ |
| ≥ 5 | 🟡 Часть текста вероятно сгенерирована ИИ |
| < 5 | ✅ Текст скорее всего написан человеком |

| Статус | Значение | Что делать |
|---|---|---|
| `✓ готово` | текст собран и проверен целиком | — |
| `⚠ частично` | часть фрагментов не проверилась, вердикт по остальному | «Перепроверить упавшие» |
| `✗ детектор` | Яндекс не ответил ни после повторов | повторить позже; при желании уменьшить «Символов на запрос» в «Ещё…» |
| `✗ нет текста` | книга не отдала доступных глав (весь текст под замком) | проверить ссылку и доступ аккаунта |
| `✗ сбой парсинга` | страница не открылась / изменилась разметка | посмотри лог и повтори; пришли фрагмент лога автору |

## ⚠️ Selenium и антивирусы

Программа управляет Chrome программно — некоторые антивирусы считают такое поведение подозрительным и молча удаляют `chromedriver.exe`. Признаки: «Не удалось запустить Chrome» или окно закрывается сразу.

Что делать:

- добавить папку с программой в исключения антивируса;
- при необходимости добавить в исключения драйвер из кэша: `%USERPROFILE%\.wdm\drivers\chromedriver\...`;
- полностью антивирус отключать не нужно — достаточно исключения для папки.

## ❓ Если что-то не получается

| Симптом | Причина и решение |
|---|---|
| `python не является внутренней...` | Python не установлен или при установке не поставлена галочка **Add python.exe to PATH**. Поставь заново с галочкой и **переоткрой** окно `cmd` |
| `install.bat` закрывается мгновенно | запусти его из `cmd` (перетащи файл в окно консоли и нажми Enter) — будет видно текст ошибки |
| «venv не найден» при запуске `run.bat` | сначала прогони `install.bat` |
| Не стартует браузер | нет Chrome; антивирус съел драйвер; обнови Chrome и повтори `install.bat` |
| Первая глава идёт долго | скачивается драйвер Chrome — разово |
| Много `✗ детектор` | Яндекс режет или грузит длинные запросы: в «Ещё…» уменьши «Символов на запрос» и увеличь «Попыток на фрагмент API» |
| «сессия: анонимно» при заполненном `.env` | неверный логин/пароль, включена 2FA или `.env` лежит не рядом с `main.py` (нужен `AT_LOGIN`/`AT_PASSWORD`) |
| В тексте главы источник `body` | страница отдала текст нестандартно, в анализ мог попасть служебный текст сайта — результат по такой главе стоит перепроверить |
| Прогресс встал | «Стоп» (прервётся на текущей главе), затем «Перепроверить упавшие» |
| Нужно разобрать сбой | приложи файл из `logs\<дата>\` |

## ⚖️ Дисклеймер

> Инструмент предназначен **только для ознакомительных целей** и служит для нейродетекции — автоматической проверки текста на следы генерации ИИ.
>
> Результаты **оценочные** и не являются юридическим заключением. Анализ выполняется по доступной части произведения (без аккаунта — по бесплатному фрагменту), которая может не отражать стиль автора на всём объёме книги.
