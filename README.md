# Author.today NeuroDetector — Desktop

Десктопное приложение (Python + PyQt6) для проверки книг с [author.today](https://author.today) на нейросетевой текст через Yandex NeuroDetector API. Собирает текст доступных глав, отправляет в детектор, показывает процент ИИ и вердикт. Работает с пачками ссылок.

> **Расширение для браузера:** [LeDXIII/author-today-neurodetector-extension](https://github.com/LeDXIII/author-today-neurodetector-extension) — проверка прямо на странице книги, без Python и Selenium. Десктопная версия нужна для массовых проверок: список ссылок, история, экспорт, повтор сбоев, доступ к купленным главам.

> ⚠️ **Важно:** по умолчанию анализируется только **бесплатный фрагмент** произведения. Число закрытых платным доступом глав выводится отдельной колонкой, но вердикт относится к прочитанной части. Результат по полной книге может отличаться.

## Установка

### Требования

| Компонент | Назначение |
|---|---|
| Windows 10/11 | — |
| Google Chrome | текст глав отдаёт только настоящий браузер |
| Python 3.10 или новее | среда выполнения |
| ~200 МБ на диске | зависимости и браузерный драйвер |

### 1. Скачать

Зелёная кнопка **Code → Download ZIP**, либо:

```cmd
git clone https://github.com/LeDXIII/author-today-neurodetector.git
```

Распаковать в папку без кириллицы и пробелов в пути (`D:\neurodetector`). Файл `install.bat` должен лежать рядом с папкой `src`.

### 2. Установить Python

Проверка наличия — `Win + R` → `cmd`:

```cmd
python --version
```

Если версия 3.10 или выше — этот пункт можно пропустить. Иначе:

1. Скачать установщик с [python.org/downloads](https://www.python.org/downloads/) (любая версия 3.10+).
2. В первом окне установщика включить `Add python.exe to PATH` — без этой опции приложение Python не найдёт.
3. После установки перезапустить окно `cmd` (PATH читается только при запуске) и повторить `python --version`.

### 3. Установить зависимости

Двойной клик **`install.bat`**: создаёт виртуальное окружение `venv`, ставит библиотеки из `requirements.txt`, скачивает драйвер Chrome, создаёт `.env` из шаблона. Занимает пару минут и много выводит в окно; признак успеха — `Готово! Запустите run.bat для старта GUI`.

### 4. Запуск

Двойной клик **`run.bat`**. Первый запуск дольше: поднимается браузер.

### Из консоли

```cmd
cd /d D:\neurodetector
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Использование

1. Вставить ссылки в верхнее поле, по одной в строке. Принимаются `https://author.today/work/618826`, `/work/618826`, просто `618826` и ссылки читалки `/reader/618826/5908671`. Дубликаты исключаются, нераспознанные строки показываются перед стартом.
2. При необходимости изменить параметры (см. [Настройки](#настройки)).
3. Нажать **Начать проверку**.
4. Прогресс — двумя полосами: книги и главы внутри текущей книги, рядом оценка оставшегося времени.
5. Двойной клик по строке — подробности по каждой главе (статус, знаки, источник, попытки) и по каждому фрагменту детектора.

### Кнопки

| Кнопка | Действие |
|---|---|
| Стоп | прерывает на ближайшей главе; собранное отправляется в детектор |
| Перепроверить упавшие | повторяет книги без вердикта и книги с малым объёмом текста |
| Экспорт | отчёт в TXT, CSV или JSON |
| Копировать отчёт | тот же отчёт в буфер обмена |
| Список из файла | загружает ссылки из `.txt` / `.csv` |

**Повтор без пере-парсинга.** Текст каждой книги сохраняется в локальный кэш. При отказе детектора повтор отправляет уже собранный текст, к сайту не обращаясь.

**История.** Все проверки складываются в SQLite (`data/history.db`), доступны на вкладке «История» с поиском и фильтрами. Там же очистка кэша текста: записи остаются, удаляются только тексты.

## Принцип работы

### Оглавление

Страница `/work/{id}` читается по HTTP, список глав берётся из `ul.table-of-content`. Закрытая платным доступом глава отдаётся **без ссылки** — это строка оглавления с иконкой замка и подсказкой «Платный доступ». Такие главы считаются отдельно и выводятся в колонке «Замки», чтобы «8 из 8» не выглядело полным ответом для книги из 23 глав.

### Текст глав

Главу отрисовывает клиентский скрипт (Knockout.js) — в исходном HTML контейнер пуст, поэтому каждая глава открывается в headless Chrome. Ожидание построено по стабильности объёма текста, а не по фиксированной паузе: в среднем ~1.6 с на главу.

Извлекается только содержимое `#text-container`: абзацы `<p>`, при их отсутствии — текст контейнера. Служебный текст страницы (карточка книги, меню, уведомления) в детектор не отправляется: классифицированный как человеческий, он выдаёт ложное «0% / написан человеком» для книг с высоким процентом генерации.

### Возрастной гейт 18+

Для книг с меткой 18+ анонимному посетителю глава не отдаётся: вместо читалки открывается страница «Для доступа к некоторым произведениям вы должны быть старше 18 лет» с кнопкой «Да, мне есть 18» и без контейнера текста.

Кнопка нажимается автоматически. Сайт отвечает кукой `AdultUser`, после чего глава читается и без входа в аккаунт. Профиль Chrome между запусками переиспользуется, поэтому подтверждение происходит один раз. Если кнопка не найдена, книга получает статус `🚫 заглушка сайта`, а не вердикт.

### Платные главы

Глава считается платной при двух одновременных условиях: текста нет **и** в отрендеренной странице виден блок оплаты. Платная глава останавливает обход книги, собранный текст отправляется на проверку. Ошибка загрузки платной не считается: она повторяется до трёх раз, а после неудачи глава пропускается без остановки книги. Падение браузера лечится перезапуском с переносом сессии.

### Отправка в NeuroDetector

Сервер Яндекса обрывает обработку длинного текста примерно на 30-й секунде (400 000 знаков — ответ за ~21 с, 700 000 — обрыв на 30.1 с). Текст режется на фрагменты ~90 000 знаков по границам глав, статистика сегментов суммируется. Классификация идёт по сегментам, поэтому сумма по фрагментам эквивалентна одному большому запросу.

Ошибки сети, обрывы соединения, 5xx и 429 (с учётом `Retry-After`) повторяются до 4 раз с экспоненциальной паузой. Если API сообщает о слишком длинном фрагменте, он делится пополам. Непроверенная часть помечается статусом `⚠ частично` с указанием, что именно упало.

## Настройки

В строке под полем ссылок:

| Параметр | По умолчанию | Описание |
|---|---|---|
| Макс. глав | 20 | глав с одной книги. Больше — точнее вердикт и дольше проверка |
| Задержка, с | 2.0 | пауза между главами |
| вход из .env | включена | проверять также доступные аккаунту главы |
| пропускать свежие проверки | выключена | не пере-парсить книгу, успешно проверенную за последние 24 часа |

В диалоге «Ещё…»:

| Параметр | По умолчанию | Описание |
|---|---|---|
| Ждать JS-рендер | 12 с | верхняя граница ожидания отрисовки главы |
| Таймаут загрузки страницы | 45 с | — |
| Попыток на главу | 3 | повторы при сбое загрузки или рендера |
| Попыток на фрагмент API | 4 | повторы при отказе детектора |
| Символов на запрос | 90 000 | размер фрагмента: меньше — надёжнее, но запросов больше |
| headless | включён | работа без окна браузера |
| не грузить картинки | выключено | ускоряет проверку |
| кэшировать текст | включён | нужен для повтора без пере-парсинга |
| профиль Chrome | включён | переиспользование профиля: в нём живут кука `AdultUser` и сервисные куки сайта |

Значения сохраняются между запусками.

## Доступ к аккаунту

Логин нужен только для глав, закрытых покупкой или подпиской: у авторизованного аккаунта они появляются в оглавлении обычными ссылками и парсятся наравне с бесплатными.

```cmd
copy .env.example .env
```

```
AT_LOGIN=почта
AT_PASSWORD=пароль
```

Вход выполняется по HTTP (CSRF + `POST /account/login`), сессия переносится в браузер. При неудаче проверка продолжается анонимно, причина выводится в строке состояния («сессия: анонимно», подробности при наведении). Файл `.env` находится в `.gitignore`, пароль в логи не попадает. Аккаунты с 2FA не поддерживаются.

## Статусы и вердикт

| % ИИ | Вердикт |
|---|---|
| ≥ 50 | 🔴 Большая часть текста вероятно сгенерирована ИИ |
| ≥ 5 | 🟡 Часть текста вероятно сгенерирована ИИ |
| < 5 | ✅ Текст скорее всего написан человеком |

Процент считается от классифицированных сегментов — `(AI + LIKELY_AI)` против `(HUMAN + LIKELY_HUMAN)` — той же формулой, что и расширение, поэтому две программы на одном тексте не расходятся.

| Статус | Значение |
|---|---|
| `✓ готово` | текст собран и проверен целиком |
| `⚠ мало текста` | в среднем меньше ~1 500 знаков на главу; вывод статистически слабый |
| `⚠ частично` | часть глав или фрагментов не проверилась, вердикт по остальному |
| `🚫 заглушка сайта` | вместо текста глав отдавалась страница-подтверждение (18+ или вход) |
| `✗ детектор` | Яндекс не ответил после всех повторов |
| `✗ нет текста` | доступных глав нет — весь текст под замком |
| `✗ сбой парсинга` | страница книги не открылась или изменилась разметка |

У обычной главы 12 000–35 000 знаков, поэтому средний объём на главу — основной признак корректности проверки.

## Yandex NeuroDetector API

- **Endpoint:** `POST https://yandex.ru/lab/neurodetector/api/analyze/text`
- **Авторизация:** не требуется, API-ключ не используется
- **Запрос:** `{"text": "..."}`
- **Ответ:**

```json
{
  "ok": true,
  "results": {
    "stats": {
      "segments_count": 100,
      "AI_count": 10,
      "LIKELY_AI_count": 15,
      "LIKELY_HUMAN_count": 30,
      "HUMAN_count": 45
    },
    "segments": [{"len": 120, "text": "…", "label": "AI"}]
  }
}
```

## Возможные проблемы

| Симптом | Причина и решение |
|---|---|
| `python не является внутренней или внешней командой` | Python не установлен или не включена опция `Add python.exe to PATH`; переустановить и перезапустить `cmd` |
| `install.bat` закрывается сразу | запустить из открытого `cmd`, перетащив файл в окно — будет видна ошибка |
| `venv не найден` | не выполнен `install.bat` |
| Не запускается браузер | Chrome не установлен, антивирус удалил `chromedriver.exe` либо Chrome обновился — перезапустить `install.bat` |
| Много `✗ детектор` | Яндекс обрезает или перегружает длинные запросы: уменьшить «Символов на запрос», увеличить «Попыток на фрагмент API» |
| Много `🚫 заглушка сайта` | сайт меняет разметку страницы подтверждения возраста: включить «вход из .env» или отключить headless |
| `сессия: анонимно` при заполненном `.env` | неверные данные, включённая 2FA или `.env` не рядом с `main.py` |
| Проверка стоит | «Стоп» прерывает на текущей главе, затем «Перепроверить упавшие» |
| Нужно разобрать сбой | приложить файл из `logs\<дата>\` |

### Selenium и антивирусы

Управление Chrome выполняется программно, и некоторые антивирусы реагируют на это как на бот-поведение, удаляя `chromedriver.exe`. Достаточно добавить в исключения папку приложения или драйвер из кэша `%USERPROFILE%\.wdm\drivers\chromedriver\`. Отключать антивирус целиком не требуется.

## Дисклеймер

> Инструмент предназначен **только для ознакомительных целей** и служит для нейродетекции — автоматической проверки текста на следы генерации ИИ.
>
> Результаты носят **оценочный характер** и не являются юридическим заключением. Анализ выполняется по доступной части произведения (без аккаунта — по бесплатному фрагменту), которая может не отражать стиль автора на всём объёме книги. Точность принадлежит Яндексу и растёт с объёмом проверенного текста: короткий фрагмент способен дать как ложное подозрение, так и ложную «чистоту».
>
> Ответственность за использование инструмента и за соответствие проверки правилам author.today лежит на использующем его лице.
